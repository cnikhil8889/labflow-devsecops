# Responsible AI-assisted engineering

This initial portfolio implementation was AI-assisted. Nikhil should run, inspect and explain the implementation before presenting it in interviews. AI-generated code is not evidence of independent mastery.

Use only approved tools; share synthetic fixtures and redacted diagnostics. Never submit secrets, patient data, proprietary source or internal URLs. Review suggested changes, run automated checks, document limitations, and keep human responsibility for merges and vulnerability decisions. Do not auto-execute model-generated shell commands from logs or untrusted text.
